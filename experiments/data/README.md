# Data for the experiments

Put the Upworthy Research Archive's exploratory packages file in this folder.

1. Open https://osf.io/jd64p/ and go to **Files**.
2. Download the CSV whose name starts with `upworthy-archive-exploratory-packages`.
3. Move it into this `experiments/data` folder. Don't rename it.

The file is not uploaded to GitHub (this folder's `.gitignore` skips it); anyone re-running the
experiments downloads it the same way.

About the data: 22,666 headline versions from 4,873 real tests run by Upworthy from 2013 to 2015.
In each test several headlines were written for the same story and shown to real readers, and the
archive records how many people saw each version and how many clicked.

Citation: J. N. Matias, K. Munger, M. Aubin Le Quere and C. Ebersole, "The Upworthy Research
Archive, a time series of 32,487 experiments in U.S. media", Scientific Data 8 (2021).
